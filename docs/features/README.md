# Feature Documentation Index

Setiap folder di direktori ini menjelaskan satu fitur dari sisi maintenance, bukan panduan pengguna akhir.

Gunakan README fitur saat:

- Menambah endpoint baru.
- Mengubah rule bisnis.
- Mengubah struktur database terkait fitur.
- Menulis test atau debug bug production.
- Melakukan refactor lanjutan ke clean architecture.
